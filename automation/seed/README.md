# Özel içerik için başlangıç dizini

Bu herkese açık depo gerçek paylaşım paketlerini, PDF alıntılarını, hesap izinlerini veya özel içerik kayıtlarını içermez. Hazır paketler kullanıcının mevcut çalışma alanında korunur. Bu dizindeki `output/` ve `state/` klasörleri Git ve Docker dağıtım bağlamı dışında tutulur.

Uygulama ilk dağıtımda boş bir içerik paneliyle açılabilir. Sosyal hesap yetkilendirmesi ve özel içerik aktarımı ayrı aşamalardır; dosyaların bu depoda bulunmaması bir hesap bağlantısı kurulmuş olduğu anlamına gelmez.
